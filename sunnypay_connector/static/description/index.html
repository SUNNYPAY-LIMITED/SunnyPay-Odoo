Seamless Payments for Odoo

Integrate Mobile money, Cards, Crypto, and Bank Transfers directly into your ERP.

The SunnyPay Connector bridges the gap between your Odoo operations and modern payment methods. Automatically sync transactions, manage merchants, and reconcile invoices without leaving Odoo. Designed for businesses that need real-time financial visibility.

Key Features

Auto-Synchronization

keep your data in sync with automated cron jobs running every 15 minutes.

Real-Time Webhooks

Instant status updates for payments. No more guessing if a customer has paid.

Financial Dashboard

Track revenue, transaction volumes, and merchant growth from a dedicated dashboard.

Supported Payment Methods

  • Mobile Money: M-Pesa, MTN MoMo, Airtel Money, Tigo Pesa
  • Cards: Visa, Mastercard
  • Crypto: Bitcoin, Ethereum, Stablecoins & etc
  • Bank: Direct Transfer, EFT

How to Configure

  1. Install the module.
  2. Go to SunnyPay > Configuration > Settings.
  3. Enter your API Key and Secret from the SunnyPay Dashboard.
  4. Click Test Connection.
  5. Enjoy seamless synchronization!
